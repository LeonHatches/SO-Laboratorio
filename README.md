# SO-Laboratorio

Archivos de los laboratorios 03 y 04 de Sistemas Operativos.

```text
lab03/
  resueltos/
  propuestos/
  README.md
lab04/
  resueltos/
  propuestos/
  README.md
```

- [Laboratorio 03: procesos](lab03/README.md)
- [Laboratorio 04: señales y pipes](lab04/README.md)

Los programas utilizan llamadas de Linux/POSIX. Compilarlos y ejecutarlos en Linux, con GCC y G++ disponibles. Cada archivo C o C++ es un programa independiente; no se compilan todos juntos en un único ejecutable.

Se conserva la lógica de los ejemplos resueltos, incluidos los ejemplos de zombis, huérfanos y las limitaciones de sincronización presentes en la guía. Las correcciones de transcripción y las ampliaciones se indican en las instrucciones de cada laboratorio. Los propuestos no llevan comentarios en el código.

Se incluyen únicamente fuentes, scripts e instrucciones. No se incluyen ejecutables, capturas ni documentos Word.
